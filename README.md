# Malik Diyaolu's portfolio

Next.js portfolio, statically exported to Cloudflare Pages at https://0xy7d.xyz.

## Development

Use Node.js 22 or newer and pnpm 8.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

## Content

Experience, selected projects, and the Klorion Labs link live in `lib/portfolio.ts`.

Recent Thoughts fetches `https://thoughts.0xy7d.xyz/feed.json` in the browser. The feed is generated by the `0xblog` repository on each blog build, so publishing a new article does not require rebuilding this portfolio. The three newest valid entries link back to the original articles.

Deploy the blog's feed change before deploying the portfolio integration. The feed needs the CORS header in the blog's `public/_headers` to allow access from Cloudflare Pages, previews, and local development. When the feed cannot load, the portfolio offers a link to the writing site instead.

The main branch's GitHub Actions workflow builds and deploys the static `out` directory to Cloudflare Pages.
